⚡ TES Charger V3 韌體安裝

初次安裝，或從 V2 升級至 V3

📋 開始之前

1

使用 Chrome 或 Edge 瀏覽器（Firefox 不支援 WebSerial）

2

用 USB 線將 TES Charger 主板連接至電腦（勿透過 Hub）

3

點下方「開始安裝」按鈕，選擇正確的 COM 連接埠

⚠ 安裝時會清除設定，請事先記錄 WiFi 密碼。

🔌 一鍵燒錄

點擊後選擇裝置連接埠，全程自動完成（約 30–60 秒）。

您的瀏覽器不支援 WebSerial，請改用 Chrome 或 Edge。

📱 安裝完成後

1

裝置重啟後，手機或電腦連接 WiFi：TES-Charger（無密碼）

2

開啟瀏覽器前往 http://192.168.4.1，在「設定」填入家用 WiFi

3

儲存後重啟。之後透過 Web UI 的「韌體更新」按鈕即可 OTA 升級

常見問題：
• 看不到 COM 埠 → 請安裝 CP210x 驅動（或 CH340）
• 燒錄失敗 → 按住主板 BOOT 鍵再接 USB，放開後重試
• 原始碼與問題回報：GitHub
